# Лендинг «Личная CRM»

Одна страница. Обе кнопки «Открыть приложение» ведут на https://app.crmgelos.ru.

## Как запустить у себя

```
pnpm install
pnpm dev      # страница на http://127.0.0.1:4321
pnpm build    # готовая страница в папке dist/
```

## Где что лежит

| Что | Где |
|---|---|
| Блоки страницы и тексты | `src/components/` |
| Адрес приложения | `src/config.ts` |
| Название вкладки и описание для поисковиков | `src/pages/index.astro` |
| Цвета, шрифты, отступы (дизайн-токены) | `src/styles/tokens.css` |
| Шрифт Onest | `public/fonts/` |
| Иконка во вкладке | `public/favicon.svg` |
| Макет | `design/` |

## Как выкатывается

Сама: после каждого push в ветку `main`.

1. GitHub Actions собирает страницу (`pnpm build`) — на сервере ничего не собирается
2. Загружает папку `dist/` на сервер в `/var/www/landing` через `rsync --delete`: лишние старые файлы удаляются
3. Проверяет, что https://crmgelos.ru отвечает 200 и что https://crmgelos.ru/version.txt — это коммит, который только что выкатили

Ход выкатки — вкладка Actions на GitHub: зелёная галочка — новая версия на сайте, красный крестик — что-то сломалось, смотреть шаг с ошибкой.

Стенда и отката нет: сломалось — исправляем и пушим новую версию.

Сценарий — `.github/workflows/deploy.yml`. Настройки в GitHub (Settings → Secrets and variables → Actions):

| Что | Где | Значение |
|---|---|---|
| Ключ деплоя (приватный) | секрет `DEPLOY_SSH_KEY` | на сервере его открытая часть разрешает только загрузку в `/var/www/landing` |
| Адрес сервера | переменная `DEPLOY_HOST` | 153.76.167.1 |
| Пользователь на сервере | переменная `DEPLOY_USER` | `landing` |
| Отпечаток сервера | переменная `DEPLOY_KNOWN_HOSTS` | чтобы не подключиться к чужому серверу |
